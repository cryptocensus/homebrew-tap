# Homebrew tap

```sh
brew install maqsatkendjebekov/tap/cryptocensus
```

[CryptoCensus](https://github.com/MaqsatKendjebekov/cryptocensus) reads the cryptography
that SSH and TLS servers advertise, grades it for post-quantum readiness, proves weak
algorithms with a live key exchange, and writes a hardened sshd config and a CycloneDX CBOM.
The formula installs the release binary for macOS (Apple Silicon, Intel) and Linux
(x86_64, arm64).
